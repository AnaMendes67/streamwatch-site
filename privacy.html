Política de Privacidade — StreamWatch

Última atualização: 26/02/2026

A StreamWatch é uma aplicação de gestão de séries e filmes. Esta Política de Privacidade explica que dados são recolhidos, para que são utilizados e quais são os teus direitos enquanto utilizador.

1. Dados recolhidos

Recolhemos apenas os dados necessários para o funcionamento da aplicação:

  • Dados de conta: endereço de email e credenciais de autenticação.
  • Dados introduzidos pelo utilizador: informações sobre filmes, séries, progresso e preferências guardadas na aplicação.
  • Dados técnicos essenciais: informação necessária para garantir o funcionamento, segurança e integridade do serviço (ex.: registos técnicos).

Não recolhemos dados sensíveis.

2. Finalidade do tratamento

Os dados são utilizados exclusivamente para:

  • Criar e gerir a tua conta.
  • Permitir o acesso seguro à aplicação.
  • Guardar e sincronizar a tua lista e progresso.
  • Garantir a segurança e funcionamento correto do serviço.

3. Onde os dados são guardados

Os dados são armazenados em infraestrutura segura fornecida por um prestador técnico de serviços cloud utilizado para suportar o funcionamento da aplicação (incluindo base de dados e autenticação).

O acesso aos dados é protegido por mecanismos de segurança que garantem que cada utilizador apenas pode aceder à sua própria informação.

4. Partilha de dados

A StreamWatch não vende nem partilha dados pessoais para fins comerciais.

Os dados podem ser processados por fornecedores técnicos estritamente necessários para o funcionamento da aplicação.

5. Conservação dos dados

Os dados são mantidos enquanto a conta do utilizador estiver ativa ou enquanto necessário para fornecer o serviço. O utilizador pode solicitar a eliminação da sua conta e dos dados associados.

6. Direitos do utilizador

Nos termos da legislação aplicável, o utilizador pode solicitar:

  • Acesso aos seus dados.
  • Correção de dados incorretos.
  • Eliminação da conta e dos dados associados.
