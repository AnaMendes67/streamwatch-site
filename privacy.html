Política de Privacidade — StreamWatch

Última atualização: 2026-02-26

A StreamWatch é uma aplicação de gestão de séries e filmes. Esta política explica que dados recolhemos, para que os usamos e quais são os teus direitos.

Dados que recolhemos

  • Conta: email e credenciais de autenticação (geridos pelo Supabase).
  • Dados na app: listas e informações que tu guardas (ex.: itens, progresso, preferências).
  • Dados técnicos (opcional): informação necessária para o funcionamento e segurança do serviço (ex.: logs de erro).

Como usamos os dados

  • Para criar e gerir a tua conta e permitir o login.
  • Para guardar e sincronizar a tua lista e progresso entre dispositivos.
  • Para manter o serviço seguro e a funcionar corretamente.

Onde os dados são guardados

Os dados são guardados em infraestrutura do Supabase (base de dados e autenticação). O acesso aos teus dados é restringido por mecanismos de segurança (ex.: regras por utilizador).

Partilha de dados

Não vendemos os teus dados pessoais. Os dados podem ser processados por fornecedores técnicos (ex.: Supabase) estritamente para permitir o funcionamento da app.

Retenção

Mantemos os dados enquanto a tua conta existir ou enquanto for necessário para fornecer o serviço. Podes pedir a eliminação da conta.

Os teus direitos

Podes solicitar acesso, correção ou eliminação dos teus dados e da tua conta. Para isso, contacta-nos através do email abaixo.
